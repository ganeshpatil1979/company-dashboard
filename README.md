# Forbes Global 2000 Intelligence Platform

Management-grade analytics dashboard built with Streamlit.

## Features

- Executive Dashboard
- Industry Analysis
- Geographic Intelligence
- Company Benchmarking
- Financial Analytics
- AI Insights

## Installation

```bash
pip install -r requirements.txt
```

Run

```bash
streamlit run app.py
```

## Deployment

Push to GitHub.

Deploy from:

https://share.streamlit.io

Main File:

```text
app.py
```

Data Location:

```text
data/Forbes_2000_Companies_2026.csv
```
